# 🐍 Snake & Ladder Game - The Prank Edition 😂

A fun, interactive snake and ladder game with a twist! After winning the game, players face a vault challenge, and if they pass, they get a hilarious surprise!

## 🎮 Game Features

### 1. **Snake & Ladder Game** (`index.html`)
- Classic 10x10 board with 100 squares
- 2-player gameplay
- Realistic snake and ladder placements
- Smooth animations and visual feedback
- Responsive design for mobile and desktop

**Board Snakes:**
- 17 → 4, 54 → 31, 62 → 42, 87 → 36, 93 → 73, 99 → 79

**Board Ladders:**
- 3 → 22, 5 → 14, 9 → 31, 20 → 38, 32 → 61, 51 → 72, 57 → 96, 71 → 91

### 2. **Vault Challenge** (`vault.html`)
After a player wins the snake and ladder game:
- Players must select the correct pattern (1 → 2 → 3)
- Numbers are shuffled randomly on a 3x3 grid
- Visual feedback for correct and wrong selections
- Interactive animations for selection confirmation

### 3. **Prank Ending** (`fool.html`)
Upon successfully completing the vault challenge:
- Animated "YOU FOOL" message on a black background
- Glitch effects and pulsing animations
- Laughing emoji bounce effect
- Option to play again or share the game

## 🚀 How to Play

1. **Start the Game**: Open `index.html` in a web browser
2. **Roll the Dice**: Click the "Roll Dice" button to move
3. **Climb Ladders**: Land on a ladder to move up
4. **Avoid Snakes**: Land on a snake and move down
5. **Reach 100**: First player to reach square 100 wins!
6. **Unlock the Vault**: After winning, select the pattern 1 → 2 → 3
7. **Get Pranked**: See the surprise "YOU FOOL" message!
